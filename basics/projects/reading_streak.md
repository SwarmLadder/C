# Reading streak

A tutor tracks minutes read each day. Identify the earliest longest consecutive streak meeting a target.

## Deliverable

Return start and length. Ties favor earliest; no qualifying day returns {0,0}.

1. Choose a representative input, an empty or smallest valid input, and a boundary case. Predict the exact output for each.
2. Implement `reading_streak` in [the starter](../starter/reading_streak.c). Check the required behavior with `make check TASK=reading_streak`.
3. Compare streaks under two different targets and explain which statistics can only decrease.

Review your implementation against [the worked project](../solutions/reading_streak.c). The extension is assessed by demonstration and code review.
